# GAME_DESIGN.md

# Ashvale — Game Design Document

## 1. Общая концепция

**Жанр:** top-down action RPG с исследованием мира, развитием поселения, данжами и экипировкой.

**Визуальный стиль:** оригинальный детализированный pixel art с видом сверху. По уровню читаемости и уютности можно ориентироваться на качественные современные pixel-art RPG, но без копирования персонажей, окружения, интерфейса, механик или других узнаваемых элементов существующих игр.

**Ключевая идея:**

Игрок выбирает один из трёх классов, исследует опасные территории вокруг разрушенного поселения, сражается с монстрами в открытых зонах и данжах, получает монеты, покупает экипировку и восстанавливает поселение. Новые здания открывают новые возможности, товары и улучшения.

Основной игровой цикл:

> Исследование → бой → награда → развитие героя → развитие поселения → новые зоны и данжи → более сильные враги → новые награды.

---

## 2. Мини-лор

Когда-то регион Ashvale был спокойной населённой землёй, которую защищали древние Хранители.

После магической катастрофы под землёй открылись Разломы. Из них начали появляться опасные существа, древние руины ожили, а большая часть населения покинула регион.

Спустя годы Разломы снова начинают усиливаться.

Главный герой прибывает в последнее полуразрушенное поселение региона. В нём осталось лишь несколько жителей, большая часть зданий разрушена, торговля практически отсутствует.

По мере исследования мира герой находит новых людей, помогает им и возвращает их в поселение. Постепенно разрушенный лагерь превращается в живой укреплённый городок.

Главная долгосрочная задача героя — исследовать источник Разломов, уничтожать существ, восстанавливать поселение и постепенно возвращать контроль над регионом.

Сюжет должен быть лёгким и не мешать основному gameplay.

---

## 3. Камера и управление

### Камера

- Вид сверху.
- Камера следует за персонажем.
- Курсор мыши определяет направление атаки и прицеливания.
- Персонаж может двигаться независимо от направления прицела.

### Управление на PC

| Кнопка | Действие |
|---|---|
| `W` | движение вверх |
| `A` | движение влево |
| `S` | движение вниз |
| `D` | движение вправо |
| `Мышь` | направление прицеливания |
| `ЛКМ` | обычная атака |
| `1` | Skill 1 |
| `2` | Skill 2 |
| `3` | Skill 3 |
| `Q` | использовать зелье здоровья |
| `E` | использовать зелье маны |
| `Space` | уклонение / короткий рывок |
| `F` | взаимодействие с NPC, сундуками, дверями и объектами |
| `I` | инвентарь и экипировка |
| `M` | карта мира |
| `Esc` | пауза / настройки |

### Общие правила управления

- Атаки направляются в сторону курсора.
- Нельзя требовать от игрока открывать инвентарь во время боя для использования зелий.
- Активные способности всегда доступны на HUD.
- Зелья здоровья и маны всегда отображаются на HUD вместе с текущим количеством.
- Интерфейс должен ясно показывать cooldown способностей и зелий.

## 4. Классы персонажа

В начале игры игрок выбирает один из трёх классов.

Для первой версии класс фиксируется для текущего сохранения.

У каждого класса:

- одна обычная атака;
- три активных способности;
- здоровье;
- мана;
- экипировка;
- общий dodge;
- собственный стиль боя.

---

# 4.1 Воин

**Оружие:** меч.

**Стиль:** ближний бой, высокая живучесть, хороший урон по группам врагов.

### Обычная атака

Комбо из трёх ударов:

1. быстрый удар;
2. второй быстрый удар;
3. более сильный завершающий удар.

Обычная атака не расходует ману.

### Skill 1 — Рассекающий удар

Широкий удар мечом перед персонажем.

- наносит повышенный урон;
- поражает нескольких врагов;
- небольшой расход маны.

### Skill 2 — Боевой рывок

Воин резко движется в сторону курсора.

- наносит урон врагам на пути;
- помогает сокращать дистанцию;
- средний расход маны.

### Skill 3 — Вихрь клинков

Несколько мощных круговых ударов вокруг персонажа.

- высокий AoE-урон;
- большой расход маны;
- длинный cooldown.

---

# 4.2 Маг

**Оружие:** посох.

**Стиль:** дальний бой, сильные способности, высокий расход маны.

### Обычная атака

Магический снаряд в сторону курсора.

Не расходует ману.

### Skill 1 — Арканный скачок

Короткий телепорт в направлении курсора, чтобы держать дистанцию.

- бесплатный по мане, использует существующий cooldown слота 1;
- путь ограничен стенами, закрытыми воротами, телами врагов и границами мира;
- безопасная точка проверяется перед кастом и при срабатывании;
- прямого урона и неуязвимости не добавляет;
- руна подготовки, следы текущего sprite и короткая вспышка прибытия.

### Skill 2 — Арканные оковы

Дальний магический снаряд с умеренным уроном и станом.

- расходует ману, имеет отдельный cooldown;
- обычные враги получают полный стан, элиты — сокращённый;
- босс невосприимчив к стану, но получает урон;
- текущая атака прерывается; активный стан не продлевается повторным попаданием;
- после окончания действует короткое окно иммунитета к повторному стану.

Числа мобильности и контроля заданы в `src/data/arcane.ts`, стоимость и cooldown — в конфигурациях навыков.

### Skill 3 — Метеор

Игрок выбирает область возле курсора.

Через небольшую задержку туда падает метеор.

- очень высокий AoE-урон;
- большой расход маны;
- длинный cooldown.

---

# 4.3 Лучник

**Оружие:** лук.

**Стиль:** дальний мобильный бой, позиционирование, высокий темп атак.

### Обычная атака

Выстрел стрелой в сторону курсора.

Не расходует ману.

### Skill 1 — Пронзающий выстрел

Быстрая физическая стрела проходит насквозь через несколько противников.

- до трёх разных целей по линии;
- заметно быстрее обычной стрелы;
- бесплатна по мане, использует существующий cooldown слота 1;
- emerald/teal trail и светлые искры отличают её от магических эффектов.

### Skill 2 — Тройной выстрел

Три стрелы с понятным веерным разлётом.

- физический ranged damage;
- расход маны и отдельный cooldown;
- каждая стрела имеет собственное попадание.

### Skill 3 — Дождь стрел

Игрок выбирает область у курсора.

- область заранее отмечается;
- четыре серии попаданий с фиксированными интервалами, без урона каждый кадр;
- расход маны и длинный cooldown.

Баланс находится в `src/data/skills.ts` и `src/data/advancedSkills.ts`.

---

## 5. Боевая система

Бой проходит в реальном времени.

Основные принципы:

- персонаж постоянно движется через WASD;
- игрок вручную прицеливается мышью;
- обычная атака бесплатна;
- способности расходуют ману;
- способности имеют cooldown;
- враги должны давать читаемые сигналы перед сильными атаками;
- персонаж может уклоняться;
- большинство атак можно избежать движением или dodge.

### Здоровье

Если HP достигает нуля:

- персонаж проигрывает бой;
- возвращается в поселение;
- часть текущего прогресса зоны может быть потеряна;
- уже купленная экипировка и построенные здания не теряются.

Точный штраф за смерть определяется позже.

### Мана

- тратится только активными способностями;
- обычные атаки ману не расходуют;
- медленно восстанавливается вне боя;
- может быстро восстанавливаться зельем маны.

---

## 6. Зелья

Есть два основных типа расходников:

- Health Potion;
- Mana Potion.

### Использование

На PC:

- `Q` — Health Potion;
- `E` — Mana Potion.

Игрок не должен открывать инвентарь.

### Ограничение

Базовый максимум:

- 5 зелий здоровья;
- 5 зелий маны.

### Cooldown

Каждый тип зелья имеет отдельный cooldown.

Пример:

- Health Potion: 5 секунд;
- Mana Potion: 5 секунд.

Использование Health Potion не блокирует Mana Potion.

### Уровни зелий

**Малое:**
- восстанавливает около 30%.

**Среднее:**
- восстанавливает около 50%.

**Большое:**
- восстанавливает около 70%.

Точные цифры балансируются после первых playtest.

---

## 7. Поселение

Поселение — главный центр игрока и основная мета-прогрессия.

В начале большая часть зданий разрушена.

Игрок тратит заработанные монеты на восстановление зданий.

Развитие поселения должно быть визуально заметным.

Прогресс:

> Развалины → маленький лагерь → деревня → укреплённое живое поселение.

---

# 7.1 Кузница

Для доступа к нормальной экипировке необходимо найти кузнеца и восстановить кузницу.

### Кузница I

Открывает базовое оружие и броню.

Продаёт:

- мечи;
- посохи;
- луки;
- броню;
- шлемы;
- ботинки.

### Кузница II

Открывает улучшенную экипировку.

### Кузница III

Открывает дорогие и сильные предметы для поздних зон.

---

# 7.2 Лазарет / Дом алхимика

После нахождения алхимика игрок может восстановить здание.

### Уровень I

Можно покупать:

- малые Health Potion;
- малые Mana Potion.

### Уровень II

Открываются средние зелья.

### Уровень III

Открываются большие зелья.

В будущем здание также может открывать дополнительные расходники, но это не входит в первую версию.

---

## 8. Экономика

Главная валюта — **монеты**.

Монеты можно получить:

- за убийство обычных монстров;
- за убийство элитных монстров;
- из сундуков;
- за прохождение данжей;
- за убийство босса;
- за выполнение небольших заданий;
- за события открытого мира.

Монеты тратятся на:

- строительство зданий;
- улучшение зданий;
- оружие;
- экипировку;
- зелья.

Деньги должны постоянно создавать выбор:

> купить новую экипировку сейчас  
> или  
> накопить на новое здание поселения.

---

## 9. Экипировка

Основные категории:

- оружие;
- шлем;
- броня;
- ботинки;
- дополнительный аксессуар — позже.

Оружие зависит от класса:

- Warrior → sword;
- Mage → staff;
- Archer → bow.

Экипировка может улучшать:

- урон;
- максимальное здоровье;
- максимальную ману;
- защиту;
- скорость передвижения;
- cooldown;
- другие параметры позднее.

Система не должна быть перегружена большим количеством характеристик в первой версии.

---

## 10. Мир

Игра должна создавать ощущение открытого мира, но технически состоять из нескольких связанных больших зон.

Игрок может свободно перемещаться по доступным территориям.

Пример структуры:

```text
                         Старые горы
                              |
                         Заброшенная шахта
                              |
Тёмный лес ---------- Поселение ---------- Древние руины
    |                     |                     |
Заросший храм         Южная дорога          Катакомбы
                              |
                           Болота
```

Не все зоны доступны сразу.

Новые территории открываются по мере прогресса.

---

## 11. Монстры в открытом мире

Бой не ограничен данжами.

На обычных территориях находятся:

- стандартные враги;
- группы врагов;
- элитные враги;
- мини-боссы;
- сундуки;
- небольшие лагеря;
- случайные боевые события.

Монстры после определённого времени возрождаются.

Это позволяет игроку:

- фармить монеты;
- тестировать новую экипировку;
- исследовать мир;
- сражаться без обязательного входа в данж.

---

## 12. Первые типы врагов

### Лес

- волки;
- слизни;
- пауки;
- усиленный лесной зверь.

### Руины

- скелеты;
- проклятые воины;
- магические существа;
- древние стражи.

### Горы

- големы;
- пещерные существа;
- гарпии;
- каменные стражи.

Точный список можно расширять постепенно.

---

## 13. Данжи

Данжи — более сложный контент внутри каждой большой территории.

Один данж должен занимать примерно 5–10 минут.

Пример структуры:

> вход → бой → развилка → бой / сундук → элитный противник → следующая комната → босс → награда.

Данжи не должны быть огромными лабиринтами.

### Награды

Во время прохождения:

- монеты с монстров;
- сундуки;
- шанс получить экипировку.

После завершения:

- фиксированная награда монетами;
- повышенный шанс хорошего предмета.

После первого прохождения:

- сюжетный прогресс;
- открытие новой территории или возможности.

## 15. Прогресс по миру

Одних монет недостаточно для открытия всей игры.

Важные боссы дают сюжетные предметы — например, **Осколки печати**.

Они не используются как обычная валюта.

Они служат ключами для дальнейшего продвижения.

Пример:

> победить Королеву пауков → получить Осколок печати → открыть северный проход → получить доступ к следующей территории.

Это не позволяет игроку полностью пропустить progression простым фармом монет.

---

## 16. NPC

В поселении постепенно появляются NPC.

Минимальный набор первой версии:

### Кузнец

- продаёт оружие и экипировку;
- связан с кузницей.

### Алхимик

- продаёт Health Potion и Mana Potion;
- связан с Домом алхимика.

### Староста / хранитель поселения

- объясняет основной сюжет;
- помогает направлять игрока к новым территориям.

Дополнительные NPC могут добавляться позже.

## 18. Цели игрока

### Короткая цель

- победить текущую группу врагов;
- найти сундук;
- закончить комнату данжа;
- заработать монеты.

### Средняя цель

- купить новое оружие;
- улучшить броню;
- построить кузницу;
- улучшить зелья;
- победить босса зоны.

### Долгосрочная цель

- восстановить поселение;
- открыть все территории;
- победить главных боссов;
- разобраться с источником Разломов;
- собрать сильную экипировку.

---

## 19. Художественное направление

Игра использует оригинальный pixel-art стиль.

Основные характеристики:

- вид сверху;
- хорошо читаемые персонажи;
- выразительные анимации;
- атмосферное окружение;
- заметные эффекты атак;
- разные визуальные темы регионов;
- плавная анимация при сохранении пиксельной эстетики.

Обязательно анимировать:

- idle персонажей;
- движение;
- обычные атаки;
- каждую способность;
- попадания;
- смерть врагов;
- сундуки;
- огонь;
- воду;
- магические эффекты;
- важные элементы окружения.

Нельзя копировать конкретные ассеты, персонажей, карты или UI других игр.

---

## 20. Scope первой версии

Первая рабочая версия не должна пытаться реализовать огромную RPG.

Цель MVP:

- 3 класса;
- 1 обычная атака + 3 skills у каждого;
- WASD + mouse aiming;
- dodge;
- Health / Mana Potions;
- поселение;
- кузница;
- Дом алхимика;
- базовая экипировка;
- несколько типов монстров;
- минимум 2 полноценные открытые зоны;
- минимум 1 законченный данж;
- минимум 1 босс;
- монеты;
- строительство;
- сохранение прогресса;
- полноценный игровой цикл.

После того как этот цикл будет интересным, можно расширять игру новыми регионами, данжами, зданиями, предметами и врагами.

---

## 21. Что пока НЕ добавляем

Чтобы не раздувать разработку, в первой версии не нужны:

- фермерство;
- выращивание растений;
- романтические отношения;
- multiplayer;
- PvP;
- сложный crafting;
- десятки ресурсов;
- профессии;
- огромные города;
- сотни NPC;
- процедурно сгенерированный бесконечный мир;
- сложная система талантов;
- десятки классов.

Сначала необходимо сделать качественным основной цикл:

> бой → награда → развитие → исследование → данж → поселение.

---

## 22. Ключевые принципы проекта

1. Бой должен быть приятным даже без награды.
2. Все три класса должны ощущаться заметно по-разному.
3. Игрок должен регулярно видеть результат развития поселения.
4. Исследование мира должно иметь смысл даже без прохождения данжей.
5. Данжи должны давать более высокий риск и более высокую награду.
6. Монеты должны быть постоянно полезны.
7. Новая экипировка должна ощутимо менять силу героя.
8. Управление должно быть понятным с первых минут.
9. Интерфейс не должен мешать бою.
10. Сначала качество core gameplay, потом увеличение количества контента.
