# Ashvale hub source assets

Generated for this project with the built-in OpenAI image generation tool on 2026-08-13.

Prompt scope: an original top-down pixel-art source board containing ruined and restored forge and infirmary variants plus a restoration board, with consistent Ashvale proportions, a limited earthy palette, crisp hard pixels, no text, and transparent separation between assets.

`hub-buildings-master.png` is the untouched source board. Runtime crops are produced by `scripts/process-new-location-assets.py` without resampling or redraw.
