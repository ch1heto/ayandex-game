# Emberweb Hollow source assets

Generated for this project with the built-in OpenAI image generation tool on 2026-08-13.

Prompt scope: original charcoal-and-ember top-down pixel-art spiders with readable glowing red eyes and four compact motion strips, plus a separate biome prop board of dead trees, ember rocks, thorn brush, webs, stumps, and ember plants. The final edit replaced only the background with a flat chroma key for deterministic extraction.

The `*-master-chroma.png` files are untouched source boards. Runtime frames and props are produced by `scripts/process-new-location-assets.py` using integer crops, nearest-neighbour processing, binary alpha, and chroma-fringe cleanup.
