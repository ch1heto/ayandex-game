# Ashvale Pixel Character

1. Read `docs/art/ART_BIBLE.md` and `docs/art/CHARACTER_GUIDE.md` completely before making character art.
2. Inspect existing images in `references/characters/<character>/` and the applicable design specification before generating or editing assets.
3. Use only the approved Ashvale visual language: original pixel art, top-down / 3-quarter RPG perspective, 48×64 px character frame, centre-bottom ground pivot, upper-left lighting, and readable small-scale silhouettes.
4. Preserve the same identity in down/front, up/back, left, and right views. Do not redesign anatomy, armour, clothing, palette roles, weapon, foot baseline, or pivot between directions.
5. Match existing approved references rather than introducing a new design language. If no reference is approved, create a four-direction neutral design reference before any production sprites.
6. Review generated images for direction correctness, consistent height, readable weapon silhouette, stable lighting, and original design before saving them into the project.
7. Create reference/design work first. Create production sprites only after the reference is approved by the user.
8. Do not create animations, gameplay changes, or unrelated classes unless explicitly requested.
